## Варіант 2 — клас векторів

Реалізовано клас `Vector3D`, який зберігає декартові координати початку та кінця вектора у просторі.

Програма демонструє:
- конструктор без параметрів;
- параметризований конструктор;
- деструктор;
- введення і виведення вектора;
- обчислення довжини;
- перевантаження операторів `+` і `-`.

## Файли

- `sample_input.txt` — приклад вхідних даних;
- `sample_output.txt` — приклад результату виконання.
